THE METHOD / AND THE CHEAT

Not a fair race.
A useful experiment.

01

Same prompt, different spikes

No one told the agents to specialize. Visuals, engineering rigor, raw GPU work, and speed emerged anyway.

02

Unequal time-to-polish

Muse got one roughly thirteen-minute pass, then went read-only. Deepseek, Hunger, and Mimo kept iterating. Muse-v2 and Hy4 studied the blind builds first.

03

Human taste did the last mile

Corrections and category calls converted different spike profiles into quality. These are museum artifacts of different moments, not identical sittings.

Apex again. HUNGER APEX, MUSE Apex Protocol, and APEX VELOCITY v2 all used the word first. The source contains one literal THREE, in const T=THREE; then the single-letter alias takes the wheel. This is a real WebGL racer, with Canvas 2D on texture and minimap duty. Its own README documents Arrows/WASD, Space handbrake, Shift nitro, touch controls, three laps against three AI, and drift-charged nitro.

THE TAKEAWAY

“Compute was never the constraint. Time, taste, and quota patience were.”

All six shipped a playable 3D racer. The bugs were human-grade; so were the judgment calls that separated a technical demo from a game worth driving.
